### Функциональные требования:

| **№** | **Действующие лица или системы** | **Use Case**                                                                                                     | **Описание** |
|:-----:|:---------------------------------|:-----------------------------------------------------------------------------------------------------------------|:-------------|
|   1   | Клиент + АБС + Интернет-банк     | Клиент подаёт заявку на депозит через интернет-банк → система должна сохранить её и уведомить клиента о принятии |              |
|   2   | Бэк офис + АБС                   | Бэк-офис обрабатывает заявки в АБС вручную (для MVP)                                                             |              |


### Нефункциональные требования:

| **№** | **Требование**           |

#### Performance
| **№** | **Требование**                                                                     |
|:-----:|:-----------------------------------------------------------------------------------|

#### Design
| **№** | **Требование**                                                                          |
|:-----:|:----------------------------------------------------------------------------------------|
|   1   | Обеспечить совместимость интеграций с технологиями проекта: .NET Framework 4.5, MS SQL  |

### **Решение**
+ Текущая архитектура системы не совместима с Kafka
+ По заданию необходимо гарантировать сохранность данных
+ Нужно, максимально, использовать те технологии, которые применяются в проекте
+ Лучше избавиться от XLS-файлов и передать работу, по формированию персонального депозит-предложения, функционалу АБС 

[Схема решения](./RabbitMQ-integration.puml)

### Альтернативы (Отклонено)
   + Прямые вызовы API: АБС и без того перегружена
   + Kafka:	Текущая платформа интернет-банка не поддерживает Kafka.

**Недостатки, ограничения, риски**
+ Нужно развернуть кластер RabbitMQ
+ АБС может обрабатывать только 50 RPS
+ Смена статуса заявки в автоматическом режиме - не поддерживается. Нужно обязательно участие менеджера
