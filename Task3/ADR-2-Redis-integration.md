### Название задачи: Настроить кэширование ставок в Redis
### Автор: Зданевич Екатерина
### Дата: 03.05.2025


### Функциональные требования:
| **№** | **Действующие лица или системы** | **Use Case**                                                           | **Описание**                          |
|:-----:|:---------------------------------|:-----------------------------------------------------------------------|:--------------------------------------|
|  1.   | Бэк офис + АБС                   | Бэк офис, каждое утро, в 9:00 обновляет ставки                         | Бэк-офис вручную вводит ставки в АБС  |
|  2.   | Клиент + АБС                     | Клиент открывает интернет-банк -> видит актуальные ставки по депозитам |                                       |


### Нефункциональные требования:

#### Performance
| **№** | **Требование**                                               |
|:-----:|:-------------------------------------------------------------|
|  1.   | Время загрузки ставок для клиента должно быть меньше 1000 Мс |

#### Reliability
| **№** | **Требование**                                                                    |
|:-----:|:----------------------------------------------------------------------------------|
|  1.   | Настроить возможность предоставления актуальных данных по ставкам для всех систем |

#### Design
| **№** | **Требование**                                                                                           |
|:-----:|:---------------------------------------------------------------------------------------------------------|
|   1   | Обеспечить совместимость интеграций с технологиями проекта: БД АБС: Oracle и Интернет-банк: ASP.NET 4.5  |

### Решение:
+ отказываемся от XLS-файлов в пользу: АБС + Redis
+ АБС становится источником истины по ставкам

[Схема решения](./Redis-integration.puml)

### Альтернативы:
+ Продолжить использовать XLS-файлы: проблемы с синхронизацией, а так же сложности с версионированием файлов

**Недостатки, ограничения, риски**
+ Требуется 1 ГБ RAM для Redis
+ При падении Redis интернет-банк будет запрашивать АБС напрямую
