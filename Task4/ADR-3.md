### Название задачи: Настройка системы доступа call-центра и партнёрской платформы к информации по ставкам из АБС
### Автор: Зданевич Екатерина
### Дата: 03.05.2025


### Функциональные требования:
Как только банк запустит маркетинговую кампанию на текущих и на новых клиентов, количество звонков в кол-центр может увеличиться.
Возникает необходимость настроить быстрый доступ Партнерской платформы и Call-центра к данным которые будет (после реализации MVP) храниться в АБС.
В текущей реализации две ключевых проблемы:
1. Ставки хранятся в АБС, но они недоступны для кол-центра и платформы партнёра.
2. Ручная отправка XLS-файлов партнёрам. Что создаёт проблемы с актуальностью данных и версионированием

| **№** | **Действующие лица или системы** | **Use Case**                                                                                                   | **Описание** |
|:-----:|:---------------------------------|:---------------------------------------------------------------------------------------------------------------|:-------------|
|  1.   | АБС + Redis                      | Данные из АБС записываются в кэш Redis                                                                         |              |
|  2.   | Redis + Call-центр               | Call-центр с помощью Get-запроса получает данные из Redis                                                      |              |
|  3.   | Redis + Партнерская платформа    | C помощью скрипта, актуальные данные из Redis выгружаются (по SFTP) в файловое хранилище партнёрской платформы |              |

### Нефункциональные требования:

#### Reliability
| **№** | **Требование**                                        |
|:-----:|:------------------------------------------------------|
|  1.   | Настроить шифрование файлов для партнёрской платформы |

#### Usability
| **№** | **Требование**                                 |
|:-----:|:-----------------------------------------------|
|  1.   | Партнёр принимает только CSV-файлы через SFTP  |



### Решение:
+ настроить доступ к данным о ставках (из Redis) по API
+ написать скрипт, который будет (каждый час) выгружать данные по SFTP из Redis в папку с файлами на стороне партнёра
+ настроить шифрование CSV файла перед отправкой

[Диаграмма с решением](./ADR-3.puml)

### Альтернативы:
+ **Google Sheets API**: отклонено, потому что партнёр не поддерживает облачные решения.

**Недостатки, ограничения, риски**
+ у партнёра все равно данные могут быть устаревшими, потому что интервал обновления 1 час
+ возможная перегрузка самого Redis
